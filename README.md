## Unlocking Secrets With CyberChef  
### Steganography, Hashing, and AES Decryption in Practice

Welcome to **HandsOnProjects**, a hands on cybersecurity learning repository focused on **data transformation, hidden data extraction, hashing, and encryption analysis** using **CyberChef**.

This project demonstrates how abstract security concepts such as steganography, hashing, and AES encryption actually work in practice by walking through real workflows, evidence artifacts, and repeatable CyberChef recipes.

If you have ever wondered how hidden messages are uncovered, how hashes are verified, or how encrypted data is decrypted step by step, this repository is designed for you.

---

## 🎯 Project Purpose

The goal of this project is to bridge the gap between **theory and hands on execution** by:

- Demonstrating how CyberChef can be used as a practical analysis tool  
- Extracting hidden data embedded in files using steganography techniques  
- Performing hashing and integrity verification  
- Decrypting AES encrypted data using known keys and parameters  
- Documenting each step with reproducible workflows and evidence  

This repository complements the accompanying Medium article by providing the **actual artifacts, recipes, and outputs** used throughout the walkthrough.

---

## 🧠 What You Will Learn

By working through this repository, you will learn how to:

- Build CyberChef recipes to analyze encoded and hidden data  
- Identify and extract steganographic payloads from images  
- Perform hashing and validate data integrity  
- Decrypt AES encrypted content using CyberChef  
- Think through multi step investigation workflows rather than isolated tools  

This project emphasizes **process and reasoning**, not just final answers.

## 🔍 How This Project Works

Each analysis follows the same structure:

1. An input artifact is provided (image, encoded string, or encrypted data)  
2. A CyberChef recipe is built step by step  
3. Transformations are applied and validated  
4. Output is reviewed and documented  
5. Evidence is captured to confirm results  

This mirrors real world investigative and security analysis workflows.
